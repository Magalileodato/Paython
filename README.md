🌌 Criptografia & Compressão de Dados – Futuristic Edition 🚀

Explorando o futuro da ciência de dados, criptografia e compressão de informações com aplicações práticas, visualizações interativas e algoritmos eficientes.

🌐 Sobre o Projeto

Este projeto combina matemática aplicada, análise de símbolos, compressão de dados e técnicas de cifragem para criar soluções eficientes e visuais. Ele serve como prova de conceito de aplicação prática de conceitos teóricos em ciência de dados e segurança da informação.

Objetivos principais:

Desenvolver algoritmos otimizados para análise de dados e compressão.

Criar códigos de cifragem simples e seguros para proteção de informações.

Fornecer visualizações interativas que facilitam o entendimento dos resultados.

Demonstrar modularidade e escalabilidade, pronto para ser integrado em aplicações web.

⚡ Como Rodar

Clone o repositório:

git clone https://github.com/seu-usuario/futuristic-crypto-compression.git
cd futuristic-crypto-compression


Crie um ambiente virtual e instale dependências:

python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
pip install -r requirements.txt


Execute o backend ou scripts de visualização:

python backend/main.py
python frontend/dashboard.py


Explore os gráficos interativos e resultados.
